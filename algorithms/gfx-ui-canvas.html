UI 描画（Canvas・Anchor・Pivot）

親画面の Anchor に貼り、要素の Pivot を原点にオフセット。 解像度を変えても端に追従する。前段: カメラと投影（2D フォロー）。次: イベントと効果音。

このデモで学ぶこと
  • Anchor = 親の正規化座標（0〜1）
  • Pivot = 自分のどの点を Anchor+Offset に合わせるか
  • 解像度変更で絶対 px 固定 UI は破綻しやすい
  • スコア、ステータス、イベントメッセージは、それぞれ別の Anchor と Pivot で置く
  • ページを開いたとき、スコア、ステータス、イベントメッセージは画面の中に入っている
  • Anchor プリセットを変えると、表示が画面の外に出ないよう Offset を合わせる
  • 奥の仮のステージは、UI が走る人や足場のどこに重なるかを見る参考。動くが、クリックしても操作できない。全員同じ絵で、URL には入らない
  • 仮想画面の枠は、選んだ解像度のピクセル数。1 px は正方形。幅のスライダーはその縦横比のまま。欄が狭いときだけ、同じ割合で縮む

仮想画面は 640×360 px。1 px は正方形です。枠もこの大きさです。

青い表示がスコア、緑がステータス、金がイベントメッセージです。右の「編集する表示」で、動かすものを選びます。奥の絵は仮のステージです。走る人や足場に重なるかを見るための参考で、操作はできません。
