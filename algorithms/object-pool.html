オブジェクトプール

弾やエフェクトを毎回 new せず再利用する。 生成 (created) と再利用 (reused) のカウンタを比較する。 関連: イベントシステム · FSM。

このデモで学ぶこと
  • Acquire / Release でオブジェクトを貸し借りする
  • プール OFF では created が増え続け、ON では reused が増える
  • 画面外へ出た弾を返却して次の spawn に回す
準備完了

プール ON のまま再生 → リセット → 同じ操作を OFF で繰り返すと、created / reused の差が分かりやすい。
