イベントと効果音

ゲームイベントを Emit → SFX が購読してトーン再生。 同じページで、BGM・同時発音・音量の通り道・体力や緊張も試せます。 前段: UI 描画（Anchor・Pivot）。次: ステートマシン。

このデモで学ぶこと
  • ゲームの処理は「イベントを発行（Emit）する」だけで、音を鳴らすかどうかは知らない
  • どんな効果音を鳴らすかは購読側（SFX）が決める。発行側のコードは変えなくてよい
  • 同じイベントに、複数の購読者（音・演出など）を後から付け足せる
  • ミュートにしても、イベント自体は変わらず流れる（ログで確認できる）
  • BGM、同時に鳴る数、音量の圧縮、体力や緊張も、購読側が受けて音を変える

発音の詳細
このタブで確かめること

短い音を重ねたとき、鳴る数と、鳴らさない判断を聞き分けます。

  1. Jump、Land、Hit の周波数と長さを変えて、役割に合う音を作る。
  2. 1音、4音、8音、16音を押し、発音数とログを見る。
  3. 上限を 4 にして、「鳴らさない」「古い音を止める」「小さい音を止める」を聞き比べる。

観察: 模式図は計算、下の波形は出力の実測。ミュートでも Emit は残る。

問い: 16音がうるさいとき、直すべきなのは発音数か、それともあとでかける音量か。

別の曲への切り替え

曲Aと曲Bは別のループです。交差しているあいだは、両方の曲の音量が動きます。同じ曲の中の層とは別です。

停止

曲はまだ鳴っていません。

同じ曲のレイヤー

Base、Tension、Battle は同じ 2 秒の位置から鳴ります。動かすのは音量の割合だけです。

このタブで確かめること
  1. 再生して、ループの端でクリックがしないか聞く。
  2. すぐ切り替える、と 2 秒のクロスフェードを聞き比べる。
  3. 手で混ぜるにチェックし、Tension だけを上げて、曲そのものは変わらないことを確かめる。

問い: 場面が変わるとき、短い切り替えと長い交差のどちらが自然か。

0 でも、クリックを避けるため約 0.02 秒かけます。

音の通り道

効果音は SFX バスへ、BGM は BGM バスへ入ります。コンプレッサーは音量の山を下げます。同時に鳴らせる数は変えません。

出力の直前に、教材とは別の保護リミッタが常に入っています。オンとオフの違いは、SFX の処理前と処理後で見てください。

このタブで確かめること
  1. コンプレッサーを切ったまま 1音と 16音を鳴らし、処理前のレベルを見る。
  2. オンにして同じことをし、圧縮量と処理後のレベルを見る。
  3. 閾値と比率を変えて、山の下がり方を聞く。

問い: コンプレッサーを強くすると、鳴らなかった音は鳴るようになるか。

体力 100。フィルタ 18000 Hz。心拍なし。

緊張 0%。レイヤーは滑らかに追います。

ダックは、イベントをきっかけに BGM の音量を下げる操作です。上のコンプレッサーとは別の欄に出ます。Hit でも下がります。

このタブで確かめること
  1. BGM を鳴らしてから、緊張を 0、50、100 へ動かし、層が増えるか聞く。
  2. 体力を 40、それから 12 にして、フィルタと心拍の違いを聞く。
  3. 通常と戦闘を切り替え、成功にすると曲が下がって短い音が鳴ることを確かめる。
  4. Hit を押し、アタック・ホールド・リリースで下がり方を変える。

問い: 緊張を一気に動かしたとき、音量は段で切り替わるか、途中を通るか。

この数だけでは曲は変わりません。敵の出現イベントで、通常やタイトルから戦闘になります。

イベントだけを出すプレイ

ここはゲームの完成版ではありません。ジャンプ、着地、接触、取得が起きたら、イベントを出すだけです。音は購読側が決めます。

キャンバスを選んでいるとき、矢印と Space ではページが動きません。自動の流れは、通常、敵、戦闘、被弾、低い体力、レア、成功の順です。

このタブで確かめること
  1. 自動の流れを押し、ログの Emit と、曲・心拍・最後の短い音を対応させる。
  2. 自分で動かし、Jump と Land と Hit が、ボタンと同じ購読者で鳴るか確かめる。

問い: プレイ側のコードに、周波数を書く必要はあるか。

敵は赤い四角、コインは黄、右端の紫がレアです。レアを取るとクリアのイベントが出ます。体力が 0 になると失敗です。

時間倍率は、この動きと効果音の再生速度にかかります。BGM は「テンポも追従」のときだけ変わり、ピッチも一緒に変わります。

演習 A〜G
  1. A. Jump、Land、Hit を、役割が聴き取れる音にする。変えた値をメモする。
  2. B. 1、4、8、16 音と、上限の方式を変えて、欠けた音を比べる。
  3. C. コンプレッサーのオンとオフ、閾値と比率を変える。発音数は変わらないことを確認する。
  4. D. 曲Aと曲Bを、すぐ切り替えとクロスフェードで聞き比べる。
  5. E. Hit のダックで、アタック、ホールド、リリースを聞き比べる。
  6. F. 緊張に合わせて Tension の層が連続して変わるようにし、段での切り替えと比べる。
  7. G. 自動の流れに対して、体力、戦闘、成功が音だけで伝わるか確かめる。
