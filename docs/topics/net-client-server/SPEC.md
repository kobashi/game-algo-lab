## 学習目標
1. サーバ権威では最終位置をサーバが決めることを説明できる  
2. クライアントの不正速度をサーバが拒否できることを観察できる  
3. 信頼クライアントとの違い（P2P 対比）を説明できる  

## 操作
- 通常移動 / チート速度トグル
- サーバ最大速度・遅延
