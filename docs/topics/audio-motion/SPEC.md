## 1. 学習目標

1. 接地中の速度から、足音という離散イベントを切り出せる。
2. 速度を、Linear / Exponential / Smoothstep / Threshold で連続した音量へ写せる。
3. 自分の `stepInterval` と `sustainGain` を、動作テストで確認できる。

## 2. なぜゲームで使うか

足音は移動の区切りで、エンジン音や風は速度に連続で付きます。同じ速度でも、イベントにするかパラメータにするかで実装が分かれます。

## 3. 操作

左右とジャンプで、入門と同じシミュレーションを動かします。曲線の選択は観察用です。評価はテキスト欄の関数です。

## 4. 成功条件

空中または遅い移動では足音の間隔が 0。十分速い接地では、速いほど間隔が短い。持続音は停止時に 0、速度とともに増え、0.3 を超えない。
