## 学習目標
1. 空間をセルに分け、同じ/隣接セル内だけを候補にできる  
2. 総当たりより検査回数が減ることを同じ n で比較できる  
3. セルサイズが効くことをスライダーで観察できる  

## 概要
円をセルに登録し、セル内＋近傍セルのペアだけ距離判定。総当たりとの検査数比較。
