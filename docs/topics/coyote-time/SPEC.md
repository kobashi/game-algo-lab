## 学習目標
1. 接地を離れた直後の短い猶予でもジャンプが通ることを説明できる  
2. 猶予の有無で「崖際の操作感」が変わることを比較できる  
3. 入力エッジ（down）と猶予タイマーの組み合わせだと分かる  

## なぜゲームで使うか
厳密な接地判定だけだと、崖を少し踏み外した瞬間にジャンプが無効になり、プレイヤーは不公平に感じる。コヨーテタイムはその猶予を与える定番手法。

## 概要
- 接地中: coyote タイマーを最大値にリセット  
- 空中: タイマーを減算  
- ジャンプ: `grounded || coyoteTimer > 0` のときのみ許可（ON 時）  
- OFF 時は `grounded` のみ  

## 操作
| 操作 | 挙動 |
|------|------|
| ←→ | 移動（held）。ページはスクロールしない |
| ↑↓ | キャンバスを選んでいるときはページをスクロールしない |
| Space | ジャンプ（edge）。ページはスクロールしない |
| 足場 1・2・3 をドラッグ | 位置が変わる。床は動かない。幅と高さは変わらない。立っている足場を動かすと、キャラも一緒に動く |
| リセット | 足場を最初の配置に戻し、統計を消す |
| R | 今の足場 1 の上に戻る。配置と統計は残る |
| コヨーテ ON/OFF | 猶予の有無比較 |
| 猶予 ms | タイマー最大値 |
| URL | `coyote`, `ms`, `speed`, `x1`, `y1`, `x2`, `y2`, `x3`, `y3`。座標は hidden number（step 1。x は -66〜616、y は 48〜246）。座標の 6 キーは既定と同じでも共有 URL に残る。成功・失敗の回数は URL に入らない |
