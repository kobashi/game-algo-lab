## 学習目標
1. 接地を離れた直後の短い猶予でもジャンプが通ることを説明できる  
2. 猶予の有無で「崖際の操作感」が変わることを比較できる  
3. 入力エッジ（down）と猶予タイマーの組み合わせだと分かる  

## なぜゲームで使うか
厳密な接地判定だけだと、崖を少し踏み外した瞬間にジャンプが無効になり、プレイヤーは不公平に感じる。コヨーテタイムはその猶予を与える定番手法。

## 概要
- 接地中: coyote タイマーを最大値にリセット  
- 空中: タイマーを減算  
- ジャンプ: `grounded || coyoteTimer > 0` のときのみ許可（ON 時）  
- OFF 時は `grounded` のみ  

## 操作
| 操作 | 挙動 |
|------|------|
| ←→ | 移動（held） |
| Space | ジャンプ（edge） |
| コヨーテ ON/OFF | 猶予の有無比較 |
| 猶予 ms | タイマー最大値 |
