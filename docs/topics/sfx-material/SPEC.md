## 学習目標
1. 材質タグで SE バリアント（周波数帯）が変わることを観察できる  
2. 衝突強度で音量・ピッチがスケールすることを説明できる  
3. 物理イベント → 材質ペア → SE 選択の流れを説明できる  

## 操作
- 材質 A / B を選択して衝突
- 強度スライダー
- ミュートでログのみ

## 成功条件
材質と強度でログ上の freq/vol が変わり、トーンも変わる。
