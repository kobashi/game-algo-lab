# トピック仕様: 状態同期 vs 入力同期

| 項目 | 値 |

| id | `net-sync-modes` |
| カテゴリ | networking |
| 状態 | implemented |

| 依存 | net-p2p-demo, net-prediction |

## 学習目標
1. 状態同期は位置などスナップショットを送る方式だと説明できる  
2. 入力同期は入力だけ送り両端で同じシミュレーションを回すと説明できる  
3. 帯域・遅延耐性・チート耐性のトレードオフを比較できる  

## 操作
- モード切替（state / input）
- 遅延、送信レート
- 両端の位置誤差表示

## 成功条件
同じ操作で両モードのパケット内容と誤差の出方が異なる。
