## 学習目標
1. 入力方向へ加速し、最高速度でクランプできると説明できる  
2. 入力なしのとき減速（ブレーキ）で止まることを観察できる  
3. 速度のみモデルとの違い（慣性が残る）を言える  

## 概要
`v += a * input * dt`、`|v| > max` ならクランプ。入力 0 なら `v *= (1 - brake*dt)` 風の減速。
