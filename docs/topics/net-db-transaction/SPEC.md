## 学習目標
1. 購入処理を BEGIN → 複数更新 → COMMIT/ROLLBACK で説明できる  
2. 途中失敗でロールバックすると残高が戻ることを観察できる  
3. 原子性（全部成功 or 全部失敗）の直感を持てる  

## 操作
- 商品購入（成功/在庫切れ/通信失敗を切替）
- ログでステップ表示
- 残高・在庫の表

## 成功条件
失敗シナリオで COMMIT されず、残高・在庫が元に戻る。
