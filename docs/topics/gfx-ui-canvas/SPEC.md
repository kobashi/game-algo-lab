## 学習目標
1. Anchor が親矩形のどの点に貼るかを説明できる  
2. Pivot が要素自身の原点であることを観察できる  
3. スコア、ステータス、イベントメッセージで、残したい辺や中央に合う Anchor と Pivot を選べる  
4. 幅を変えても、辺に合わせた表示はその辺に残り、中央に合わせた表示は中央付近に残ることを確認できる  
5. 奥の仮のステージを見て、走る人や足場をいつも隠す置き方を避けられる  

## 操作
- 奥に仮のステージ。走る人、足場、コイン、敵、鳥が動く。クリックしても操作できない。位置は画面の割合。全員同じで、URL には入らない。動きを減らす設定ではポーズを止める
- 編集する表示（スコア、ステータス、イベントメッセージ）。選んだ表示の Anchor・Pivot・Offset を編集する
- ページを開いたとき、スコア、ステータス、イベントメッセージは画面の中に全部入る。スコアは右下、ステータスは左上、イベントメッセージは中央
- Anchor プリセットを変えたとき、その表示が画面内に収まるよう Offset を直す。Pivot は変えない。URL の読み込みとドラッグでは直さない
- 3 つは同時に描く。選んでいる表示だけ白枠、Anchor の点と Pivot の点を描く
- 仮想解像度切替（640×360、800×450、480×320、960×540）。高さは、そのプリセットの縦横比
- 幅の連続スライダー（320〜960、0.1 刻み、バッファ幅は四捨五入の整数）は、選んだ解像度の縦横比を保つ。`res` を付けない URL は 640×360
- 枠はバッファと同じ CSS px（1 px は正方形）。欄が狭いときだけ、縦横を同じ割合で縮める。数表は縮める前の px
- ドラッグで、選んでいる表示のオフセット。別の表示をクリックすると、その表示の編集に切り替わる。画面の外に出て残りの辺が 28 px 未満のときは、画面内の橙の「ドラッグ」からも Offset を変える。そのつまみがほかの表示に重なるときは、空いている角へずらす
- URL: `res,vieww,anchor,px,py,ox,oy`（スコア）、`ha,hpx,hpy,hox,hoy`（ステータス）、`ma,mpx,mpy,mox,moy`（イベントメッセージ）、`part`（編集する表示）

## 成功条件
幅を変えたとき、辺に合わせた表示はその辺に残り、中央に合わせた表示は中央付近に残る。走る人や足場が、いつも表示の下に隠れない。スコアは 120×48 のまま。パラメータを付けずにページを開くと、スコア、ステータス、イベントメッセージは画面の中に全部入る。演習の右上 Anchor（幅 480 / 640 / 960 で左上の x が 400 / 560 / 880、右の辺から 80 px）は、`ox=-20`・`oy=-20` を付けた URL で測ると変わらない。同じ Pivot 0.5・Offset -20 で左上 Anchor を URL から開くと、左上は (-80, -44)。Anchor プリセットの操作では Offset を直すので、この数にはならない。仮のステージは参考で、置く場所の数値は出さない。
