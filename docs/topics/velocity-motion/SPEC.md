## 学習目標
1. `position += velocity * dt` で離散時間の移動ができる  
2. 速度ベクトルと軌跡の関係を説明できる  
3. dt や速度を変えると見た目の速さが変わることを観察できる  
4. 1フレームの移動量が障害物の厚みを超えると**すり抜ける**ことを観察できる  

## 操作
| 操作 | 挙動 |
|------|------|
| vx / vy / dt | 速度と 1 ステップの時間刻み（dt 5〜200ms。大きくするとすり抜けやすい） |
| 壁でバウンス | 画面端はクランプ＋速度反転（従来どおり） |
| 障害物 | 中央の矩形。**重なっていれば反射、重なっていなければ何もしない** |
| 障害物の厚み | 8〜80 step 1（既定 24）。薄いほどすり抜けやすい |
| 再生速度 | 0.1〜1.0 step 0.1（既定 1）。物理 dt はスライダー値 |
| 軌跡 | 既定 on。1フレームごとに点 |
| 繰り返し | 画面外または壁ヒット多数で初期位置へ |
| 前回の軌跡 | リセット時に薄く残す |
| URL | `vx,vy,dt,bounce,speed,loop,trail,ghost,obs,thick` |

すり抜けたら `#status` に「すり抜けた」と出し、障害物を一瞬赤くする。
1フレームの移動距離 `|v|·dt` と厚みを並べて表示する。
