## 1. 学習目標

1. 小さなゲームの速度、着地、敵との距離、同時発音、BGM の状態を、別々の関数で音にできる。
2. 動作テストの点数と設計の文章を JSON で残せる。

## 2. 配点

足音 25、着地 15、警告 20、発音数 15、動的 BGM 15、設計の文章 10。合計 100。スライダーの位置は点数に入りません。

## 3. 操作

ゲームはイベントと状態だけを出します。「この実装で聞く」は、書いた関数をそのまま音にします。`stepInterval` の戻り値は秒で、その秒が経過するたびに足音が鳴ります。`landImpact` には、地面に触れる直前の垂直速度を渡します。発音数の上限で選んだボイスは、その場で音を止め、画面の発音数と揃えます。動作テストが採点します。JSON の保存は、保存した時点の関数と設計文を採点します。
