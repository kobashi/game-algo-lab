## 学習目標
1. ワールド座標とスクリーン（カメラ相対）の変換を説明できる  
2. プレイヤー追従カメラの遅延・デッドゾーンを観察できる  
3. カメラ移動で背景とキャラの見え方がどう変わるか説明できる  

## 操作
- ←→ でプレイヤー移動
- 追従速度・デッドゾーン（矩形を画面に描く）
- カメラ中心とプレイヤー（target）を両方描き、遅れを数値表示
- 再生速度 0.1〜1.0、軌跡、繰り返し
- URL: `follow,dead,speed,loop,trail,scene`（`scene` は `measure` / `action` / `explore`。計測が既定で、既定のときは URL に出さない）
- 場面: 計測は幅 1200 の平面。アクションと探索は幅 3600 で、カメラが横へスクロールする。アクションはトゲ・ノコ・コイン（スペースでジャンプ）。探索は絵。ギミックに触れても歩く速さは変わらない
- 提出課題（`?course=intro`）にヒントを出す。アクションは追従係数を大きくデッドゾーンを狭く、探索は追従係数を小さくデッドゾーンを広く。数値の答えは書かない

## 成功条件
プレイヤーが端に寄るとカメラが動き、ワールド座標は変わらずスクリーン座標が変わる。
