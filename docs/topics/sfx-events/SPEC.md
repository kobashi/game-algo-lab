## 学習目標
1. ゲームイベントから SE 再生を購読できる（疎結合）  
2. Web Audio で短いトーンを合成再生できる  
3. 無音環境でもログで発火を追える  

## 操作
| 操作 | 挙動 |
|------|------|
| Jump 等ボタン | 対応イベントを Emit → 購読者がトーン再生 |
| 対象イベント | 調整するイベントを選ぶ（config の既定は残す） |
| 周波数 / 長さ / 音量 | 選択中イベントの上書き。freq 80〜1200 step 10、dur 0.02〜0.5 step 0.01、gain 0〜0.3 step 0.01（既定 0.08） |
| ミュート | 再生せずログのみ |
| 波形 | 鳴らした音の波形（青）と包絡線（黄）をキャンバスに残す |
| 直前の音をもう一度 | 最後に鳴らしたパラメータで再生 |
| URL | `ev`, `freq`, `dur`, `gain` |
