## 残す契約

入門の演習・課題・詳説が今の文面のまま成り立つように、次は変えない。

- 最初に開くタブは効果音。Jump / Land / Hit / Pickup のボタン、直接 Emit、ログ、模式図、ミュート、対象イベント、周波数・長さ・音量がすぐ見える。
- イベント名は `Jump` `Land` `Hit` `Pickup` `UI`。購読側が `js/maps/sfx-events-config.js` の周波数と長さを既定にし、選択中のイベントだけを上書きする。
- ログの文は `Emit ${名前}`、`SE play ${freq}Hz ${dur}s g=${gain}`、`SE (muted) ${freq}Hz ${dur}s`、`SE (gain 0)`、`SE (no AudioContext)`。ミュート中も Emit は出る。
- `playTone(freq, dur, gain = 0.08)` は残す。音を鳴らす前に模式図を更新する。
- URL の `ev` `freq` `dur` `gain` はこれまでどおり。適用のあと、その値を選択中イベントの上書きとして保存する。
- 模式図は計算で描く。青が波形、黄が包絡線。実測の波形は別のキャンバスで、AnalyserNode の時間波形である。
- 発行側（ボタン、実験プレイ、自動の流れ）は音の関数を呼ばない。`emit` だけを呼ぶ。
- AudioContext は最初の操作で1つ作り、音のたびに作り直さない。ページを離れるときに閉じる。

## 学習目標

1. ゲームイベントから SE 再生を購読できる（疎結合）
2. Web Audio で短いトーンを合成再生できる
3. 無音環境でもログで発火を追える
4. BGM のループ、別の曲へのクロスフェード、同じ曲のレイヤーの音量比を聞き分けられる
5. 同時発音数の上限と、音量を圧縮するコンプレッサーが別の仕事だと確認できる
6. 体力・緊張・場面・イベントに合わせて、購読側が音を変えられる

## 画面

タブは「効果音」「BGM」「ミキサー」「状況」「実験プレイ」。タブの値は URL の `tab`（`oneshot` `bgm` `mixer` `dynamic` `sim`）。各タブに、学ぶこと、手順、比較、観察のポイント、問いを置く。詳しい数値は折りたたみ。

共通: ミュート、発音数、BGM / SFX / Master のレベル（dBFS）、経路、ダッキング量、場面、ログ、実測波形、初期値へ戻す、比較プリセット、URL コピー、JSON の書き出しと読み込み。

### 効果音

これまでの操作に加える。波形（sine / square / sawtooth / triangle / noise）、音量、周波数、長さ、アタック、リリース、ピッチのばらつき、再生速度、同時発音の上限（1〜16）、競合（unlimited / reject / oldest / quietest）。試験ボタンは 1・4・8・16 音、連打、全停止。発音中の音を一覧する。クールダウン 50 ms は既定オフ。

unlimited でも安全のため 32 音で止め、いちばん古い音を止めてその旨をログする。quietest は発音中の音量の推定で、音ごとの Analyser は作らない。上限とコンプレッサーは別である。

### BGM

Play / Pause / Resume / Stop、ループ、曲 A と曲 B、音量、フェードイン・アウト、クロスフェード 0〜5 秒、すぐ切り替える、再生位置とループの長さ。音源は 2 秒で位相がつながる合成音（曲 A、曲 B、タイトル、成功と失敗のジングル）。ライセンスのあるファイルは置かない。

同じ曲の Base / Tension / Battle は同じ時刻から再生し、音量比だけを変える。別の曲への切り替えは曲ごとの音量を交差させる。スライダー 0 でも、クリックを避けるため約 0.02 秒のランプを入れる。

BGM タブで曲を選んで再生すると、場面による曲の切り替えをいったん止める。緊張のレイヤーと体力のフィルタは止めない。「場面のBGMに戻す」、または場面の値が変わったときに、場面の曲へ戻る。

### ミキサー

経路は次のとおり。

```text
BGM → ローパス → 体力の音量 → ダック → BGM音量 → BGMメーター → Master
SFX → SFX音量 → SFXメーター（処理前）→ そのままの経路と DynamicsCompressor
    → 処理後メーター → Master
Master → そのままの経路と DynamicsCompressor → 保護リミッタ → 出力
```

各バスに音量、ミュート、ソロ（BGM と SFX）、メーター。コンプレッサーはオンで圧縮側を聞き、オフでその経路をバイパスする。バイパス中の表示は「バイパス」。オンのときだけ、そのノードの `reduction` を圧縮量として出す。処理前と処理後のレベルを並べる。

保護リミッタは教材の比較対象ではなく、コンプレッサーを切っても出力が過大にならないように常に入っている。比較は SFX バスの処理前と処理後で見る。Master 音量の既定は控えめにする。

### 状況

| パラメータ | 範囲 | 音への効き方 |
|---|---|---|
| Health | 0〜100 | 50 以上はほぼそのまま。下がるほど BGM のローパスが閉じ、BGM が少し小さくなる。50 未満で心拍。低いほど間隔が短い |
| Tension | 0〜100 | 今の曲の Tension レイヤーを 0〜100%。急変はならす |
| EnemyCount | 0〜10 | 表示と実験プレイの数。スライダーだけでは曲を切り替えない |
| GameState | title / normal / battle / success / fail | 待機、曲 A、曲 B、BGM を下げてジングル |
| TimeScale | 0.2〜2 | 効果音の playbackRate。BGM は「テンポも追従」のときだけ |

場面が同じ値のままなら、曲をやり直さない。成功と失敗のジングルも、同じ結果への再設定では鳴らし直さない。

ダッキングは Hit、Explosion、ImportantPickup（レアな Pickup を含む）で BGM のゲインを下げる。量 0〜24 dB、アタック 0〜300 ms、ホールド 0〜1000 ms、リリース 50〜3000 ms。同時の要求は、その時刻のゲインの小さい方を採用する。コンプレッサーとは別の表示にする。

### 実験プレイ

小さな横移動。ジャンプ、着地、敵への接触、コイン、レア、敗北、クリアはイベントだけを出す。自動の流れは、通常 → 敵の出現 → 戦闘 → 被弾 → 低い体力 → レア取得 → 成功。キャンバスにフォーカスがあるとき、矢印と Space ではページをスクロールしない。

## URL と JSON

既定値と同じキーは共有 URL に付けない。追加のキーは `tab` `wave` `atk` `rel` `pit` `rate` `vmax` `steal` `cool` `bgmvol` `sfxvol` `mastvol` `loop` `xf` `song` `comp` `mcomp` `thr` `ratio` `knee` `catk` `crel` `health` `tension` `enemies` `gstate` `tscale` `bgmfollow` `layers` `duck` `ducka` `duckh` `duckr`。

JSON はコントロールと、5 イベントの上書きを持つ。`v` は 1。

## 成功条件

- `?ev=Hit&freq=880` で Hit のログは 880 Hz、Jump は 440 Hz。ミュートでも `Emit Hit` と `SE (muted)` が出る。
- BGM を鳴らしながら OneShot を重ねられ、バス音量は独立している。
- 発音数が増減し、上限の方式で欠ける音が変わる。
- コンプレッサーのオンとオフで、聞こえる経路が変わる。オンのとき圧縮量が読める。
- クロスフェードは短いランプでつながり、レイヤーは同じ再生位置から鳴る。
- Hit で BGM が下がり、緊張で Tension レイヤーが動き、低い体力で心拍とローパスがかかる。
- 場面を変えると待機・通常・戦闘・ジングルへ移り、同じ場面の再設定ではやり直さない。
- PC と狭い幅の両方で、タブと主要なボタンが画面内に収まる。
