# 応用サウンドコース — 移管表

最終更新: 2026-11-21

入門は「イベントを出して、購読側が一度だけ鳴らす」。応用は、その先の発音数・揺らぎ・バス・材質・移動・距離・音楽時間を、トピックごとに1つの目標へ分ける。トピック ID と既存 URL は変えない。成熟度（一発 / 調整 / 安定）は、入門か応用かとは別の属性のまま。

正本の並びは `js/courses/audio-stages.js`。入口は `courses/audio.html`。

## どこに置くか

| いま入門ページにまとまっている処理 | 移す先 | 入門に残すもの |
|---|---|---|
| ボイス上限、Reject / Oldest / Quietest、クールダウン、発音チップ、1/4/8/16 音 | `sfx-voice-limit`（判定は `decideVoice`） | 安全上限 32 と保護リミッタだけ。操作では出さない |
| ピッチのばらつき、再生速度 | `sfx-randomize`（音量のばらつき、複数サンプル、シャッフルバッグ、シードは元からここ） | なし |
| バス、ミュート、ソロ、メーター、コンプレッサー、ダックの時間包絡 | `audio-bus-ducking` | BGM と効果音を安全な音量で重ねて再生・停止する |
| 曲 A/B の即時切替とクロスフェード | `bgm-transition-compare`（等パワーと、切替の途中からの再切替を足す） | 1 曲の再生・一時停止・再開・停止 |
| ループ位置、一時停止、再生速度 | `bgm-loop`（再生位置は AudioContext の時刻） | 入門ではループする BGM を効果音の下で流す |
| 拍・小節への予約 | `bgm-quantize` | なし |
| 緊張レイヤー、場面ごとの曲、次の小節でのレイヤー追加 | `bgm-interactive`（通常・警戒・戦闘） | なし |
| 衝突の強さと音色 | `sfx-material` | なし |
| 速度、足音、接地、パラメータ曲線 | `audio-motion`（新規） | 実験プレイは Jump / Land / Hit / Pickup を出すだけ |
| 距離、パン、接近警告 | `sfx-spatial` | なし |
| ディレクター全体と採点 JSON | `audio-adaptive-lab`（新規） | なし |

## 共通モジュール

`js/audio/` を教材で共有する。同じ計算をページごとにコピーしない。

| モジュール | 役割 |
|---|---|
| `audio-engine.js` | AudioContext、バス、ランプ、タブ復帰とページ離脱時の解放 |
| `sfx-manager.js` | OneShot、安全上限 |
| `audio-math.js` | ボイス判定、ダック包絡、Peak と RMS |
| `parameter-mapper.js` | Linear、Exponential、Smoothstep、Threshold、平滑化 |
| `student-task.js` | 学生が書いた関数の読み込み、結果、JSON |
| `audio-checks.js` | 動作テスト。失敗文は規則を書き、期待する数値は書かない |
| `game-sim.js` | 音を選ばずイベントだけを出す横移動。Motion と総合演習もこれを使う |

各ページの模式図・メーター・読み上げは、そのトピックの観察用として残す。

## 評価と観察

観察は、ページのボタンとスライダーで聞く。評価は、テキスト欄の関数を動作テストが呼ぶ。初期の関数は、ボタンを押しただけでは合格しない。

入門の評価は、学生が入力した新しいイベント名を soundFor に渡し、その音が安全な範囲にあり、未登録の名前と戻り値が違うかを見ること。提出 URL の A と B は、既存イベントの周波数の比較。イベント名と関数は提出票に入る。入門コースの観察カード（Hit 880 Hz、Jump 440 Hz、ミュートでも Emit）はそのまま。
