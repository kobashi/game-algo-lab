## 学習目標
1. BGM / SE などをバスに分けてゲイン制御できる  
2. SE 再生中に BGM を一時減衰（ダック）できる  
3. マスターとバスの階層を説明できる  

## なぜゲームで使うか
ボイスや重要な SE のとき BGM を下げるのは定石。Mixer の考え方の入口。

## 操作
- BGM 再生/停止
- SE 発火 → BGM がダックして復帰
- バス音量スライダー

## 成功条件
SE 中に BGM メーターが下がり、終了後に戻る。
