## 学習目標
1. 着地前に押したジャンプが、着地直後に消費されることを説明できる  
2. バッファ窓（ms）の ON/OFF で操作感が変わることを比較できる  
3. エッジ入力を「今すぐ実行」と「後で実行」に分ける発想が分かる  

## 概要
ジャンプ down エッジを受けたとき接地していなければ `bufferLeft = window` をセット。  
接地した瞬間に `bufferLeft > 0` ならジャンプを実行してバッファをクリア。
