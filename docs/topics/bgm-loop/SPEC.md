## 学習目標
1. イントロ区間とループ区間の違いを説明できる  
2. ループ終端で intro に戻らず loopStart へ飛ぶことを観察できる  
3. シームレスループの再生ヘッドモデルを説明できる  

## なぜゲームで使うか
戦闘曲・探索曲は「冒頭だけ1回、その後ループ」が定番。実装は再生位置の分岐。

## 操作
- 再生 / 一時停止 / リセット
- イントロ長・ループ長スライダー
- タイムライン上の再生ヘッド

## 成功条件
再生ヘッドがループ終端で loopStart に飛び、intro を再通過しない。
