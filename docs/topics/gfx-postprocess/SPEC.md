## 学習目標
1. シーン描画後に画面全体へ効果をかける流れを説明できる  
2. 彩度・ビネット・簡易ブルームのパラメータを操作できる  
3. 各効果が最終ピクセルにどう効くかの直感を持てる  

## 操作
- 彩度 / コントラスト / ビネット / ブルーム強度
- リセット

## 成功条件
スライダーで画面全体の見え方が変わり、オフにすると元に戻る。
