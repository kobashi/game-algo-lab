# トピック仕様: BGM 切替方式の比較

| 項目 | 値 |
|------|-----|
| id | `bgm-transition-compare` |
| カテゴリ | audio |
| 状態 | implemented |
| 成熟度 | oneshot |
| 作成日 | 2026-07-28 |
| 依存 | bgm-loop, bgm-quantize, audio-bus-ducking |

## 学習目標
1. 即時切替・クロスフェード・拍同期切替の違いを観察できる  
2. 各方式の聴感と実装コストのトレードオフを説明できる  
3. ゲイン曲線（線形クロスフェード）を可視化で読める  

## 操作
- 曲 A / B を切替（方式セレクト）
- クロスフェード長・BPM
- ゲインメーター

## 成功条件
3 方式で A→B のゲイン遷移が異なるタイムラインになる。
