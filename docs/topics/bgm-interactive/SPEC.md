# トピック仕様: 拍同期・レイヤー型 BGM

| 項目 | 値 |
|------|-----|
| id | `bgm-interactive` |
| カテゴリ | audio |
| 状態 | implemented |
| 成熟度 | oneshot |
| 作成日 | 2026-07-28 |
| 依存 | bgm-loop, bgm-quantize, audio-bus-ducking |

## 学習目標
1. ベース／ドラム／ボス層など複数レイヤーのゲイン合成を説明できる  
2. ゲーム状態変化を次小節頭でレイヤーに反映できる  
3. クロスフェード付きレイヤー起動の流れを観察できる  

## 操作
- 探索/戦闘トグル（次小節でボス層）
- 各レイヤー mute / ゲイン
- 拍グリッド表示

## 成功条件
戦闘 ON でボス層が次小節から立ち上がり、OFF で減衰する。
