## 学習目標
1. 三角形メッシュの頂点・インデックスの関係を説明できる  
2. UV がテクスチャ上の座標だと観察できる  
3. マテリアル（色・タイリング）が見た目を変えることを確認できる  

## 操作
- UV オフセット / スケール
- ワイヤー表示トグル
- マテリアル色

## 成功条件
UV を動かすとテクスチャ模様がメッシュ上でスライドし、ワイヤで三角形が見える。
