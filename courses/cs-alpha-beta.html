1. このコードがすること

このファイルには、次の 2 つがあります。

  • AbKind・AbNode: 第 12 回の MmKind・MmNodeと、まったく同じ形の列挙型・クラスです（名前の頭文字が Mm から Ab に変わっただけ）。
  • AlphaBeta.Evaluate(n, alpha, beta): α-β 法つきの Min-Max。返す値は、枝刈りをしない第 12 回の Minimax.Evaluate とまったく同じです。違うのは、答えに関係ない枝を読まずに済ませる点だけです。

AbNode のフィールド・プロパティ・コンストラクタの説明は第 12 回と同じなので、ここでは繰り返しません。 考え方そのものはくわしい解説で図を使って説明しているので、ここではコードとの対応に絞って説明します。

2. 新しく出てくる C# の文法

新しい文法はほとんどありません。enum・int?・取得専用プロパティ・再帰・int.MinValue は 第 12 回のとおりです。ここでは、コードの形として少しだけ目にとまる 2 点を説明します。

2.1 if に付いていない { } だけのブロック

if (n.Kind == AbKind.Max)
{
    int v = int.MinValue;
    foreach (var child in n.Children)
    {
        v = Math.Max(v, Evaluate(child, alpha, beta));
        if (v >= beta)
            return v; // β カット
        alpha = Math.Max(alpha, v);
    }
    return v;
}

// Min
{
    int v = int.MaxValue;
    foreach (var child in n.Children)
    {
        v = Math.Min(v, Evaluate(child, alpha, beta));
        if (v <= alpha)
            return v; // α カット
        beta = Math.Min(beta, v);
    }
    return v;
}

最初の { } は if (n.Kind == AbKind.Max) に付いたブロックです。ここまでは第 1 回からずっと出てきた、普通の if のブロックです。 その次の // Min というコメントの下にある { } には、if も for も付いていません。 C にも、if や for なしでいきなり { } を書く書き方があり、ただの「区切り（スコープ）」として使えます。C# でも同じです。

Evaluate は AbKind.Max なら前半のブロックの中で必ず return するので、AbKind.Min（それ以外）のときだけ、 後半の { } まで実行が進みます。if ... else { ... } と書かずに、if ブロックの中の return で 「もし Max ならここで終わり」を表し、残りの { } を「そうでなければ」の代わりに使っている形です。

2.2 ループの途中の return

if (v >= beta)
    return v; // β カット

foreach の中で return すると、そのループだけでなく、Evaluate メソッドそのものがすぐに終わります。 これは C の for ループの中で return するのと同じ動きです。break だとループだけ抜けてメソッドの続きが実行されますが、 return はメソッドごと抜けるので、まだ読んでいない残りの子（n.Children の続き）は、そもそも foreach が回らず、評価されません。 これが、答えに関係ない枝を読まずに済ませる仕組みの土台です。

これまでに出たもの: enum・int? と ??・取得専用プロパティ・再帰・int.MinValue（第 12 回）、 class・フィールド・メソッド（第 1 回）、List<T>・foreach・var（第 9 回）。 C と同じもの: if、>=・<=、{ } だけのブロック、ループ内の return。

3. 計算式とアルゴリズムのポイント

3.1 α と β の更新、カットの条件

v = Math.Max(v, Evaluate(child, alpha, beta));
if (v >= beta)
    return v; // β カット
alpha = Math.Max(alpha, v);
v = Math.Min(v, Evaluate(child, alpha, beta));
if (v <= alpha)
    return v; // α カット
beta = Math.Min(beta, v);

MAX の節点では、子を 1 つ評価するたびに v をこれまでの最大に更新し、v が β 以上になったら、その場で v を返して打ち切ります（β カット）。 打ち切らずに済んだ場合は、alpha を v でさらに大きくしてから次の子へ進みます。MIN の節点はこの逆で、 v が α 以下になったら打ち切り（α カット）、そうでなければ beta を更新します。 α・β の意味そのもの（自分の下限・相手の上限）はくわしい解説の 3 節で説明しています。

Evaluate の中の alpha・beta 引数は、C の double *p のような参照渡しではなく、普通の int の値渡しです。 alpha = Math.Max(alpha, v); で書き換えても、変わるのはこの呼び出し（この節点）の中だけで、呼び出し元の alpha・beta は変わりません。 親から子へは、更新した後の値をそのまま引数として渡します（Evaluate(child, alpha, beta)）。

3.2 根の呼び出し方

/// 根: Evaluate(root, int.MinValue, int.MaxValue)

くわしい解説でのα＝−∞、β＝+∞という開始値は、このコードでは int.MinValue・int.MaxValue（第 12 回）にあたります。 「まだ何も分かっていない」ことを、その型で表せるいちばん外側の値で表しています。 α-β 法は、枝刈りをしてもしなくても、根から返る値は必ず同じです。第 12 回の Minimax.Evaluate と見比べると、 if・return の位置が増えただけで、MAX は最大・MIN は最小という規則そのものは変わっていないことが分かります。

4. 呼び出してみる（Main と出力）

第 12 回で組み立てたのと同じ、デモの既定の木（js/maps/alpha-beta-tree.js、葉 12 枚）を AbNode で組み立てて呼び出します。 

using System;

public static class Program
{
    public static void Main()
    {
        AbNode l1a = new AbNode("L1a", "葉L1a", AbKind.Leaf, 5);
        AbNode l1b = new AbNode("L1b", "葉L1b", AbKind.Leaf, 3);
        AbNode l1 = new AbNode("L1", "応手L1", AbKind.Max);
        l1.Children.Add(l1a);
        l1.Children.Add(l1b);

        AbNode l2a = new AbNode("L2a", "葉L2a", AbKind.Leaf, 7);
        AbNode l2b = new AbNode("L2b", "葉L2b", AbKind.Leaf, 9);
        AbNode l2 = new AbNode("L2", "応手L2", AbKind.Max);
        l2.Children.Add(l2a);
        l2.Children.Add(l2b);

        AbNode l = new AbNode("L", "手L", AbKind.Min);
        l.Children.Add(l1);
        l.Children.Add(l2);

        AbNode m1a = new AbNode("M1a", "葉M1a", AbKind.Leaf, 4);
        AbNode m1b = new AbNode("M1b", "葉M1b", AbKind.Leaf, 2);
        AbNode m1 = new AbNode("M1", "応手M1", AbKind.Max);
        m1.Children.Add(m1a);
        m1.Children.Add(m1b);

        AbNode m2a = new AbNode("M2a", "葉M2a", AbKind.Leaf, 1);
        AbNode m2b = new AbNode("M2b", "葉M2b", AbKind.Leaf, 3);
        AbNode m2 = new AbNode("M2", "応手M2", AbKind.Max);
        m2.Children.Add(m2a);
        m2.Children.Add(m2b);

        AbNode m = new AbNode("M", "手M", AbKind.Min);
        m.Children.Add(m1);
        m.Children.Add(m2);

        AbNode r1a = new AbNode("R1a", "葉R1a", AbKind.Leaf, 6);
        AbNode r1b = new AbNode("R1b", "葉R1b", AbKind.Leaf, 8);
        AbNode r1 = new AbNode("R1", "応手R1", AbKind.Max);
        r1.Children.Add(r1a);
        r1.Children.Add(r1b);

        AbNode r2a = new AbNode("R2a", "葉R2a", AbKind.Leaf, 7);
        AbNode r2b = new AbNode("R2b", "葉R2b", AbKind.Leaf, 4);
        AbNode r2 = new AbNode("R2", "応手R2", AbKind.Max);
        r2.Children.Add(r2a);
        r2.Children.Add(r2b);

        AbNode r = new AbNode("R", "手R", AbKind.Min);
        r.Children.Add(r1);
        r.Children.Add(r2);

        AbNode root = new AbNode("root", "自分の手番", AbKind.Max);
        root.Children.Add(l);
        root.Children.Add(m);
        root.Children.Add(r);

        int value = AlphaBeta.Evaluate(root, int.MinValue, int.MaxValue);
        Console.WriteLine("Evaluate(root, int.MinValue, int.MaxValue) = " + value);
    }
}

実行結果:

Evaluate(root, int.MinValue, int.MaxValue) = 7

第 12 回の Minimax.Evaluate(root) と同じ 7 です。 木の形と葉の値は同じでも、こちらは途中で枝刈りをしながら計算しています。

5. まとめと、やってみよう

この回で出てきた C# の文法です。後の回では、ここへのリンクだけを置きます。

文法ひとことでC では
{ } だけのブロックif・for なしの区切り。前の if が必ず return するので、実質「そうでなければ」になるC と同じ書き方ができる
ループ内の returnループだけでなく、メソッドごとすぐに抜けるC と同じ

やってみよう

  1. MAX 側の if (v >= beta) と、その次の return v; // β カット の 2 行をまとめてコメントアウトして実行し（1 行だけだと return が必ず実行されてしまうので注意）、根の値が変わらないこと（枝刈りをやめても答えは同じこと）を確かめる。
  2. Evaluate を 第 12 回で作った木以外（自分で値を変えた木）にも適用し、Minimax.Evaluate と同じ値になることを確かめる。

確かめよう

問 1. // Min の下の { } には、if や for が付いていない。なぜここだけ実行される？

その前の if (n.Kind == AbKind.Max) のブロックが、Max のときは必ず return して関数を終えるからです。ここまで実行が進むのは、Max でなかった（Min だった）ときだけです。

問 2. foreach の中で return v; すると、何が起こる？

ループだけでなく Evaluate メソッドそのものが終わります。まだ読んでいない残りの子は評価されません。

問 3. Evaluate(root, int.MinValue, int.MaxValue) と、枝刈りをしない Minimax.Evaluate(root) の返り値を比べるとどうなる？

同じ値になります。α-β 法は、枝刈りをしてもしなくても、根から返る答えを変えません。
