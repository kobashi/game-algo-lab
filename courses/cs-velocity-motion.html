1. このコードがすること

このファイルには、次の 2 つがあります。

  • Vec2: x と y をひと組にして持つ小さな入れ物。位置にも速度にも使えます。
  • VelocityMotionExample.Integrate(p, v, dt): 位置 p・速度 v・時間 dt から、新しい位置を計算して返します。p 自身は変わりません。

2. 新しく出てくる C# の文法

2.1 struct: 値型。フィールドをまとめて宣言、コンストラクタ

public struct Vec2 { public double X, Y; public Vec2(double x, double y){X=x;Y=y;} }

C で書くと

struct Vec2 {
    double x, y;
};

C#（1 行にまとめて書いてある）

public struct Vec2
{
    public double X, Y;
    public Vec2(double x, double y)
    {
        X = x;
        Y = y;
    }
}

struct は C の構造体と同じ感覚で使えます。値型で、代入や引数渡しのたびに中身がコピーされます。 第 1 回の class（BallWorld）は参照型で、渡しても実体は 1 つのままでした。ここが対照的です。

public double X, Y; は、同じ型のフィールドをコンマで区切って 1 行にまとめて書けるという意味です。C の double x, y; と同じ書き方です。

public Vec2(double x, double y){X=x;Y=y;} はコンストラクタです。型名と同じ名前のメソッドで、new で作るときに自動で呼ばれ、フィールドへ初期値を入れます。 C では、こういう初期化は vec2_make(x, y) のような別の関数を自分で用意して呼ぶ必要がありました。

2.2 式形式メンバー => と、型を省略した new(...)

public static Vec2 Integrate(Vec2 p, Vec2 v, double dt)
    => new(p.X + v.X * dt, p.Y + v.Y * dt);

=> は、中身が return 式; だけのメソッドを短く書く書き方です（式形式メンバー）。次の書き方と同じ意味です。 

public static Vec2 Integrate(Vec2 p, Vec2 v, double dt)
{
    return new(p.X + v.X * dt, p.Y + v.Y * dt);
}

new(...) は、型名を省いた new です。戻り値の型がすでに Vec2 だと分かっているので、 new Vec2(...) と書かなくても、new(...) だけで「今分かっている型（ここでは Vec2）で作る」という意味になります。 第 1 回では new BallWorld() と型名を書いていました。型がはっきり分かる場面でだけ、こう省略できます。

2.3 新しい値を返して、元を変えない書き方

Integrate は、渡された p の中身を書き換えず、計算した結果を新しい Vec2 として return します。 第 1 回の BallWorld.Update は、自分の Y・V を直接書き換えていました。ここは書き方が違います。

位置を実際に進めるには、呼び出す側で p = VelocityMotionExample.Integrate(p, v, dt); のように、戻り値を p へ入れ直します。 戻り値を受け取らずに VelocityMotionExample.Integrate(p, v, dt); とだけ書くと、p は変わりません（4 節で確かめます）。

これまでに出たもの: using System;・public static class（第 1 回）、/// のコメント（第 1 回）。
C と同じもの: double、+・*。

3. 計算式とアルゴリズムのポイント

3.1 新しい位置 ＝ 今の位置 ＋ 速さ × dt

=> new(p.X + v.X * dt, p.Y + v.Y * dt);

式で書くと p' = p + v · dt です。考え方はくわしい解説の 2 節のとおりで、 横（X）と縦（Y）を、それぞれ独立に p.X + v.X * dt・p.Y + v.Y * dt と計算しているだけです（3 節の速度ベクトル）。

3.2 なぜ新しい値を返すのか

Vec2 は struct（値型）なので、引数の p には、呼び出し元の Vec2 のコピーが渡ってきます。 もし Integrate の中で p.X += v.X * dt; のように p 自身を書き換えても、それはコピーを書き換えるだけで、呼び出し元の変数は変わりません。 だから、新しい値を計算して return し、呼び出す側で p = ... と受け取る書き方になっています。

4. 呼び出してみる（Main と出力）

v = (60, -30)（1 秒に右へ 60、上へ 30）、dt = 1/60 秒で、3 フレームぶん動かします。 

using System;

public static class Program
{
    public static void Main()
    {
        Vec2 p = new(0, 0);
        Vec2 v = new(60, -30);
        double dt = 1.0 / 60;

        for (int frame = 1; frame <= 3; frame++)
        {
            p = VelocityMotionExample.Integrate(p, v, dt);
            Console.WriteLine("frame " + frame + ": x=" + Math.Round(p.X, 3) + " y=" + Math.Round(p.Y, 3));
        }
    }
}

実行結果:

frame 1: x=1 y=-0.5
frame 2: x=2 y=-1
frame 3: x=3 y=-1.5

1 フレームごとに x が 1 ずつ、y が -0.5 ずつ変わっています（60 × 1/60 = 1、-30 × 1/60 = -0.5）。y がマイナス方向へ進むのは、上へ動いているからです。

3 節で説明した「戻り値を受け取らないと p は変わらない」ことも確かめます。

Vec2 p = new(0, 0);
Vec2 v = new(60, 0);
VelocityMotionExample.Integrate(p, v, 1.0 / 60); // 戻り値を受け取らない
Console.WriteLine("x=" + p.X); // 0 のまま
x=0

確かめよう

問 1. Vec2 が class ではなく struct なのは何を意味する？

値型だということです。代入したり引数として渡したりすると、中身がコピーされます。

問 2. Integrate(p, v, dt) の戻り値を p に代入しないと、何が起きる？

p は変わりません。Integrate は自分に渡された p のコピーを計算に使うだけで、書き換えないからです。

問 3. new(60, -30) のように型名を省略できるのはどんなとき？

代入先や戻り値の型が、すでにコンパイラに分かっているときです。ここでは Vec2 v = ... や、戻り値の型が Vec2 と決まっているためです。
