1. このコードがすること

CircleCollision には、次の 2 つの判定があります。

  • Circles(x1, y1, r1, x2, y2, r2): 2 つの円が重なっているかを、true/false で返します。
  • CircleAabb(cx, cy, r, minX, minY, maxX, maxY): 円と AABB（回転していない箱）が重なっているかを返します。

どちらも「重なっているかどうか」だけを調べます。重なったあとどう動かすか（衝突応答）は入っていません。

2. 新しく出てくる C# の文法

2.1 Math.Clamp

float nx = Math.Clamp(cx, minX, maxX);
float ny = Math.Clamp(cy, minY, maxY);

Math.Clamp(value, min, max) は、値を min〜max の範囲に押し込める関数です。範囲より小さければ min、大きければ max、範囲の中ならそのままになります。

C（標準にはないので自分で書く）

float nx = fmaxf(minX, fminf(cx, maxX));

C#

float nx = Math.Clamp(cx, minX, maxX);

C の標準ライブラリには clamp に当たる関数がなく、fmin・fmax を組み合わせて書きます。C# では 1 つの関数にまとまっています。

2.2 比較の結果をそのまま return

return dx * dx + dy * dy <= rr * rr;
return dx * dx + dy * dy <= r * r;

if で分けて return true;・return false; と書かず、比較の結果（bool）をそのまま return しています。 戻り値の型が bool の Circles・CircleAabb だからこそできる書き方です。C でも比較はそのまま return できますが、戻り値は bool 型ではなく int（0 か 1）になります。

2.3 float dx = ..., dy = ...;（C と同じ）

float dx = x2 - x1, dy = y2 - y1;

同じ型の変数を、コンマで区切って 1 行で宣言・初期化しています。C とまったく同じ書き方です。

これまでに出たもの: using System;・public static class（第 1 回）、bool（第 2 回）、float（第 4 回）。
C と同じもの: <=、*・+・-、コメントの //。

3. 計算式とアルゴリズムのポイント

3.1 距離の 2 乗で比較する（Circles）

float dx = x2 - x1, dy = y2 - y1;
float rr = r1 + r2;
return dx * dx + dy * dy <= rr * rr;

くわしい解説の 2 節で説明した「平方根を使わずに比べる」方法です。 dx・dy は中心どうしの横・縦のずれ、rr は半径の和です。dx*dx + dy*dy（距離の 2 乗）と rr*rr（半径の和の 2 乗）を、2 乗のまま比べています。

3.2 Clamp で最近点を求める（CircleAabb）

float nx = Math.Clamp(cx, minX, maxX);
float ny = Math.Clamp(cy, minY, maxY);
float dx = cx - nx, dy = cy - ny;
return dx * dx + dy * dy <= r * r;

(nx, ny) が、箱の中で円の中心にいちばん近い点（最近点）です。x と y、それぞれの軸で別々に Math.Clamp を使って求めています （くわしい解説の 5 節）。あとは円の中心 (cx, cy) から最近点までの距離の 2 乗を、半径の 2 乗と比べるだけです（4 節）。

4. 呼び出してみる（Main と出力）

くわしい解説と同じ数値で、円同士・円と箱の判定を試します。 

using System;

public static class Program
{
    public static void Main()
    {
        bool missFar = CircleCollision.Circles(180, 160, 40, 320, 200, 32);
        bool touch = CircleCollision.Circles(180, 160, 40, 252, 160, 32);
        bool missNear = CircleCollision.Circles(180, 160, 40, 255, 160, 32);
        Console.WriteLine("Circles far:   " + missFar);
        Console.WriteLine("Circles touch: " + touch);
        Console.WriteLine("Circles near:  " + missNear);

        bool aabbTouch = CircleCollision.CircleAabb(480, 80, 40, 420, 120, 540, 210);
        bool aabbMiss = CircleCollision.CircleAabb(480, 79, 40, 420, 120, 540, 210);
        Console.WriteLine("CircleAabb touch: " + aabbTouch);
        Console.WriteLine("CircleAabb miss:  " + aabbMiss);
    }
}

実行結果:

Circles far:   False
Circles touch: True
Circles near:  False
CircleAabb touch: True
CircleAabb miss:  False
  • 円 A(180,160,r=40) と円 B(320,200,r=32) は離れていて False（くわしい解説 2 節の例と同じです）。
  • 円 B を (252,160) にすると、中心の距離がちょうど半径の和（72）と等しくなり、True（ぎりぎり接触）。
  • そこから 3 px 離す（(255,160)）と False に変わります。
  • 円 A の中心を (480,80)、箱を x=420,y=120,w=120,h=90 にすると、円の下端がちょうど箱の上辺に届き True。円を 1 px 上（y=79）にすると False になります。

5. まとめと、やってみよう

この回で出てきた C# の文法です。後の回では、ここへのリンクだけを置きます。

文法ひとことでC では
Math.Clamp値を範囲に押し込める標準にはない（fmin・fmax を組み合わせる）
比較結果をそのまま returnbool の戻り値に、比較式をそのまま返す戻り値は int（0/1）になる
float dx = a, dy = b;同じ型の変数をコンマで区切って宣言C と同じ

やってみよう

  1. 4 節の CircleAabb の呼び出しで、円の中心を箱の内側（例えば (480, 160)）にすると、最近点はどこになり、結果はどうなるか予想してから確かめる。
  2. Circles の 2 つの円の半径を大きくしていくと、rr * rr はどう変わるかを、実際に数値を入れて確かめる。

確かめよう

問 1. Math.Clamp(250, 100, 200) の結果は？

200。範囲より大きいので、上限に押し込められます。

問 2. Circles が平方根を計算しないのはなぜ？

距離や半径の和はマイナスにならないので、2 乗のまま比べても大小関係が変わらないからです。

問 3. CircleAabb で、円の中心の x・y がどちらも箱の範囲の中にあるとき、最近点はどこになる？

円の中心そのもの（Math.Clamp がどちらの軸でも値を変えないため）。つまり円の中心が箱の中にあり、必ず重なります。
