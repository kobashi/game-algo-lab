UI の配置 — くわしい解説

スマホでもパソコンでも、ボタンや体力バーはいつも決まった場所にあります。 でも、機器によって画面の大きさがちがうのに、なぜ「決まった場所」に置き続けられるのでしょうか。 このページでは、その仕組みである Anchor（アンカー）・Pivot（ピボット）・Offset（オフセット）を、図を使って説明します。 UI の配置のデモと合わせて読んでください。

目次
  1. 画面の大きさは機器で違う
  2. 正規化座標（0〜1 の割合）
  3. Anchor（親のどこを基準にするか）
  4. Pivot（自分のどの点を合わせるか）
  5. Offset と、3 つの組み合わせ
  6. まとめと、やってみよう

1. 画面の大きさは機器で違う

ゲームを遊ぶ機器の解像度（画面の幅と高さの px 数）は、機器によってさまざまです。 スマホもあれば、大きなモニターもあります。もし UI（ボタンなどの画面部品）の位置を「左上から何 px」という 固定の数だけで決めてしまうと、解像度が変わったときに崩れてしまいます。

2. 正規化座標（0〜1 の割合）

この問題を解決する考え方が正規化座標です。 px のような決まった数ではなく、「画面の幅の何割か」という 0〜1 の割合で位置を表します。 割合なら、画面の幅が変わっても、同じ割合の場所は「同じような見た目の位置」になります。

3. Anchor（親のどこを基準にするか）

Anchor は、UI を親（画面）のどこを基準にして置くかを、 正規化座標で決めるものです。親の左上を (0, 0)、右下を (1, 1) とします。 たとえば右上を基準にしたいなら、Anchor は (1, 0) です。

解像度が変わっても、Anchor の割合は変わりません。だから、Anchor の位置は画面の端にいつも付いていきます。

4. Pivot（自分のどの点を合わせるか）

Anchor が「親のどこを基準にするか」なのに対して、Pivot は 「UI 要素自身のどの点をその基準に合わせるか」を、同じように 0〜1 の割合で決めるものです。 自分の左上を (0, 0)、右下を (1, 1) とします。

たとえば Pivot を (1, 0)（右上）にすると、要素の右上の角が基準点に合わせられます。 Pivot を (0.5, 0.5)（中央）にすると、要素の真ん中が基準点に合わせられます。

5. Offset と、3 つの組み合わせ

Offset は、Anchor の位置から、px でどれだけずらすかです。 Anchor・Pivot・Offset の 3 つを組み合わせると、次の式で UI の左上の位置が決まります。

箱の左上 ＝ Anchor の位置 ＋ Offset − Pivot × 箱の大きさ

例として、Anchor ＝ (1, 0)（右上）、Pivot ＝ (1, 0)（要素も右上）、Offset ＝ (−24, 24) にしてみます。 画面が 640 × 360 のとき、Anchor の位置は (640, 0) です。Offset を足すと (616, 24)。 ボタンの大きさが 120 × 48 なら、Pivot × 大きさ ＝ (120, 0) なので、これを引くとボタンの左上は (496, 24) になります。

画面の幅が 480 や 960 に変わっても、Anchor は (1, 0) のままなので位置は自動で計算し直され、 上と右からの余白は同じ 24 px のままになります。幅は変わっても、この組み合わせ自体は変わりません。

6. まとめ

  • 画面の解像度は機器によって違う。px の固定位置では、幅が変わると崩れる
  • 正規化座標は、画面の大きさに対する割合（0〜1）で位置を表す
  • Anchor は、UI を親（画面）のどこを基準に置くかを正規化座標で決める
  • Pivot は、UI 要素自身のどの点をその基準に合わせるかを正規化座標で決める
  • Offset は基準からの px のずれ。箱の左上 ＝ Anchor ＋ Offset − Pivot × 大きさ
  • Anchor・Pivot・Offset を組み合わせておけば、解像度が変わっても位置の関係は保たれる

やってみよう

  1. Anchor を左上にして幅 480で開き、幅（連続）のスライダーを 960 まで動かして、ボタンの位置がどう変わるかを見る。
  2. Anchor を右上にして同じ操作をする。左上とのちがいを比べる。
  3. Anchor と Pivot を両方中央にして、ボタンをドラッグし、Offset の数値欄がどう変わるかを見る。

確かめよう

問 1. Anchor を (0, 0) にすると、位置は親のどこを基準にする？

親（画面）の左上。

問 2. Pivot を (1, 1) にすると、Anchor ＋ Offset の位置に、要素のどの点を合わせる？

要素自身の右下の点。

問 3. 画面の幅が 640 から 960 に変わると、Anchor (1, 0) の位置の x 座標（px）はどうなる？

640 から 960 に増える。Anchor の x 座標は「幅 × 1」で決まるので、幅が増えれば px の値も増えます。
